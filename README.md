# Para Karen Leici · Flores Amarillas

Un detalle de amistad para el 21 de septiembre, con diseño botánico en marfil, oliva y amarillo.

## Música (sin YouTube / sin anuncios)

No se puede alojar «Yellow» de Coldplay sin licencia. El sitio usa un reproductor local:

1. Coloca tu archivo **legal** aquí: `assets/la-mejor-parte.mp3`
2. El botón **la mejor parte** lo reproduce (inicia cerca del coro; ajusta `BEST_PART_START` en `script.js` si hace falta)
